# PulseNet Social Platform Starter

This workspace is initialized as a production-oriented foundation for building a social media platform with large-scale ambitions.

## Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- ESLint

## Quick start
1. Install dependencies:
   - `npm install`
2. Start development server:
   - `npm run dev`
3. Open in browser:
   - `http://localhost:3000`

## Initial product scope
- Home feed
- Profiles (user, creator, business)
- Communities / groups
- Messaging + notifications
- Media upload pipeline
- Moderation and trust/safety foundation
