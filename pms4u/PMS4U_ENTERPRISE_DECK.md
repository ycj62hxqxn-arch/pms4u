**Title:** Authority Before Execution  
**Subtitle:** Runtime authority infrastructure for AI agents and high-consequence enterprise workflows.

## Slide 2: The Enterprise Shift

AI is moving from generation to execution.

- First wave: text, summaries, recommendations.
- Next wave: workflow execution, API calls, approvals, operational mutation.

## Slide 5: PMS4U Solution

PMS4U inserts a constitutional authority boundary.

Before mutation, PMS4U checks:

- Current state.
- Requested transition.
- Actor authority.
- Evidence requirements.
- Runtime admissibility.

Allowed actions proceed. Inadmissible actions freeze.
